# Expense Tracker

A simple command-line Expense Tracker built with Python.

The application helps users record daily expenses, track spending by category, set a monthly budget, search expenses, and export records to a CSV file.

## Features

- Add new expenses
- Store expense name, category, amount, and date
- View all saved expenses
- Calculate total spending
- View category-wise spending summary
- Search expenses by category
- Set a monthly spending budget
- Check remaining budget or overspending amount
- Delete an expense
- Export expenses to a CSV file
- Save expenses locally using JSON

## Technologies Used

- Python
- JSON
- CSV
- `datetime`
- `pathlib`

## Requirements

- Python 3.x
